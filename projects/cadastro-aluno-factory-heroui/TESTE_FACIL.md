# Teste fácil

## Pelo navegador, sem instalar VS Code no computador

1. Coloque este projeto em um repositório GitHub.
2. No repositório, clique em **Code**.
3. Clique em **Codespaces**.
4. Clique em **Create codespace on main**.
5. Aguarde a preparação automática.
6. Quando a porta 3000 for detectada, o app abrirá no navegador.

## Para testar tudo

No Codespaces, abra:

**Terminal → Run Task → ✅ Verificar app completo**

Ou execute:

```bash
npm run test:all
```

Se o app não abrir automaticamente, vá à aba **Ports** e clique no endereço da porta **3000**.
