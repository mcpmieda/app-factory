## Como usar o arquivo legado

Use o v2 para responder perguntas de composição como:

- que tipos de login/autenticação existem como referência?
- como uma sidebar pode variar sem perder coerência?
- que padrões de card atendem settings, profile, onboarding e notifications?
- que tipos de hero/marketing podem orientar uma landing page?
- que estruturas de checkout, product list e review existem?
- que padrões de prompt/chat podem ser adaptados à geração atual?

Depois:

1. procurar equivalente no HeroUI v3 OSS/Pro atual;
2. montar com componentes atuais;
3. preservar apenas a ideia funcional/composicional;
4. não copiar código/assets proprietários do v2 sem licença aplicável.
