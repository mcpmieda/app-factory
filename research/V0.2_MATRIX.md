## Legenda

- **P2** — módulo condicional.

## Conclusões atuais

1. A Factory deve manter **Core neutro + adaptadores**, com um Codex Plugin como superfície preferencial no ecossistema OpenAI.
2. Agent Skills continuam padrão portátil; `openai/skills` não é mais fonte atual.
3. Spec Kit deve ser considerado como motor/adapter de planejamento para projetos médios e grandes, não obrigação universal.
4. shadcn + ReUI permanece eixo principal do perfil admin; HeroUI é perfil alternativo.
5. Playwright deve ter posição central na verificação de aplicações web relevantes.
6. Better Auth, Drizzle e Zod seguem como candidatos fortes, mas só viram defaults após piloto real.
7. Starter deve ser componível; monorepo, observabilidade, release automation, Storybook, pagamentos e scanners extras são módulos condicionais.

## Próximo passo

Concluir auditoria P0/P1 e transformar os achados em decisões de V0.3 + dois pilotos: um pequeno e um web-admin completo.
