# Registry / MCP Layer

## Objetivo

Distribuir padrões validados para novos projetos sem copiar manualmente arquivos ou reescrever prompts.

Itens futuros podem incluir componentes UI, layouts, páginas, configurações, `AGENTS.md`, Skills, setup de testes, scripts, workflows de CI e convenções de projeto.

## shadcn Registry

A Factory deverá avaliar `registry.json` como mecanismo principal para itens compatíveis com shadcn. MCP pode permitir que agentes pesquisem e instalem itens em linguagem natural.

## Estado atual

Não criar catálogo grande antes de existir código validado. Primeiro construir e testar starter/piloto; depois promover itens reutilizáveis ao Registry.

## Privacidade

Enquanto a Factory for privada, avaliar mecanismos compatíveis com repositório privado ou manter esta camada em preparação. Não tornar público apenas por conveniência técnica.
